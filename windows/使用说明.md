# Self Coverflow · Windows

运行下载的安装程序，然后从开始菜单打开对应语言版本。安装向导会检查 WebView2 和 Apple Music，也可选择创建桌面快捷方式和随 Apple Music 启动。

| 操作 | 效果 |
| --- | --- |
| 点击左上角的「收藏专辑」或「全部专辑」 | 切换 Apple Music 标星专辑与完整专辑列表 |
| 点击收藏按钮旁的放大镜 | 输入专辑名或艺人名，用方向键选择结果，按回车滚到专辑。搜索覆盖整个资料库。回车选中的专辑会保持居中，双击即可播放；按 Esc 恢复跟随当前唱片 |
| 点播放键两侧的箭头、按键盘 ← / → | 在当前播放的资料库专辑内切歌，首尾相接 |
| 点下一首右侧的循环按钮 | 按「不循环 → 专辑循环 → 单曲循环 → 不循环」切换。图标中央的 1 表示单曲循环。 |
| 滚动、横向拖动或点侧面封面 | 连续浏览专辑。快速拖动松手后会带一点惯性，随后对齐封面 |
| 双击封面，或在封面区域按回车 | 切换到另一张专辑时，先暂停 Apple Music 正播放的曲目，再在后台载入新专辑。再次选择当前专辑会继续播放。底部会立即显示播放中的等待提示，并轻声模拟唱片转动和读盘；快速完成的请求保持安静，Apple Music 确认目标专辑开始播放后自动消失。单击侧面封面会将它移到中央 |
| 从封面向上或向下拖出，或在「•••」菜单点「歌词」 | 上滑封面并松手会选中这张专辑、将它滚到中央，在后台开始播放并展开歌词。下拉侧面封面同样会选中并播放；下拉中央封面只展开歌词 |
| 点击同步歌词中的一行 | Apple Music 跳到该句；同一句歌词重复出现时，按点中的那一段定位 |
| 拖动歌词面板的标题栏 | 移开面板，或将它拖回唱片架的边缘吸附。吸附后移动唱片架，两者会一起移动。图钉控制两个窗口，点歌词窗右上角的 × 可单独收起歌词 |
| 在「•••」菜单切换「仿真效果」（Simulation Effects） | 等待目标专辑播放时持续转盘，暂停音乐时播放一次暂停声。默认开启，音量固定，设置自动保存 |
| 点底部中间的播放键 | 通过 Windows 媒体会话在后台暂停或继续播放。没有可控制的会话时会显示提示 |
| 停止翻看 2.5 秒 | 封面沿唱片架连续滚回当前专辑，逐渐减速停稳。滚动或拖动可随时接手。收藏视图也会临时显示正在播放的非收藏专辑 |
| 在「•••」菜单选择经典、半宽或全宽 | 经典尺寸为 472 × 306。半宽和全宽分别使用当前显示器可用宽度的一半或全部，高度均保持 306，并按 Windows 显示缩放换算 |
| 点击右上角图钉 | 浮在其他普通窗口上方，再点一次恢复先前的桌面或独立窗口模式 |
| 拖动顶部空白处 | 接近当前显示器的工作区上沿、任务栏边缘或中线时，窗口会逐渐靠拢，松手后轻轻停稳。继续拖动即可脱离 |

组件随本机 Apple Music 的资料库文件更新。它按专辑标识区分同名发行版本，收藏筛选使用专辑自己的星标。尚未缓存封面的专辑会显示音符。音频由 Apple Music 客户端播放，底部曲名来自 Windows 的媒体会话。歌词可用性取决于当前歌曲以及 Apple Music 客户端提供的歌词。

程序使用 Windows 自带的 .NET Framework 和本机的 WebView2 Runtime。窗口位置和浏览偏好分别保存在当前用户 LocalAppData 下的 CoverShelf（中文）和 CoverShelf-EN（英文）目录。资料库采用 Apple Music 默认的“音乐”文件夹位置。Windows 客户端更新格式后，资料库读取可能需要相应更新。

Windows 宿主位于 windows/src，共用界面位于 app。运行 windows/build.ps1 可重新编译。WebView2 组件的许可随程序提供。资料库元数据格式参考 [musicdb](https://github.com/pedrohgmacedo/musicdb)、[amlx](https://github.com/TwinvisPR/amlx) 和 [musicdb2sqlite](https://github.com/rinsuki/musicdb2sqlite)。
